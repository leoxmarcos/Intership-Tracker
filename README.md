## 🌌 The Idea Behind InternTrack

**Opportunities are everywhere. Staying organized is the real challenge.**

Students often apply to multiple internships but struggle to keep track of application statuses, interview schedules, deadlines, and company details.

That's where **InternTrack** comes in!

InternTrack is a centralized internship management platform designed to make the student internship journey simpler, smarter, and more organized.

From your first application to your interview updates, everything stays connected in one place.

## 💎 What Makes InternTrack Special?

### 🔐 Your Personal Career Space
A dedicated student account experience with registration, login, and profile management.

### 📊 Your Career Dashboard
Get a quick overview of your internship journey with application statistics and easy navigation.

### 💼 Application Command Center
Manage your internship applications effortlessly:
- Add, edit, and delete applications.
- Search through your application records.
- Track progress with five application statuses.
- Keep important company and role details organized.

### 📅 Never Miss an Opportunity
A dedicated calendar to organize:
- Interview schedules.
- Application deadlines.
- Important internship-related events.
- Upcoming reminders.

### 📈 Turn Applications into Insights
Interactive analytics powered by Recharts:
- Pie chart for application status distribution.
- Bar chart for monthly application activity.
- Quick statistics for applications, shortlisting, and interviews.

### 👤 Your Professional Profile
Keep your personal and academic information organized and updated.

## 🚀 Get Started

Want to explore InternTrack on your local machine?

**Step 1 — Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**Step 2 — Enter the project folder**

```bash
cd internship-tracker
```

**Step 3 — Install dependencies**

```bash
npm install
```

**Step 4 — Launch the application**

```bash
npm run dev
```

**Step 5 — Explore InternTrack**

Open the local URL shown in your terminal, usually:

`http://localhost:5173/`
